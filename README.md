# AICompass

## Project Overview

AICompass is an AI-powered platform designed to support academic integrity and responsible AI use in education.

## Problem

The increasing use of AI in education creates challenges such as plagiarism, excessive dependence on AI, and limited awareness of responsible AI use among students.

## Proposed Solution

AICompass provides tools to help students use AI more responsibly while maintaining academic integrity through plagiarism checking, paraphrasing, AI usage monitoring, and ethics education.

## Key Features

- Plagiarism Checker
- Paraphrase Tool
- AI Safety Indicator
- AI Dependency Score
- AI Ethics Learning Module
- AI Usage Declaration
- Teacher Dashboard Analytics

## UI/UX Design

The project includes a Figma prototype designed to support students and educators in monitoring and managing AI usage in academic activities.
